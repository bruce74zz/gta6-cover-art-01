Turn your own photos and a caption into a GTA-style multi-panel game cover: 5 cover layouts, 5 per-panel colour grades, Anton/Pacifico display lettering, a drag-to-crop panel editor, and one-click PNG export (1080×1080, 1080×1350, 1920×1080). Fully offline; no Rockstar assets — bring your own photos or use the bundled samples.

## Run it

Open `app/index.html` in a browser, or serve the folder with any static file server. No build step, no network calls.

Built by an AI agent for make.fun's GTA 6 cover art bounty.
